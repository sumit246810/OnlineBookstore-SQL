# Online Bookstore SQL Project

## About the Project
This is a SQL project based on an online bookstore. I created tables for books, customers, and orders and practiced SQL queries to analyze the data.

## Database Tables
- **Books:** Contains book details like title, author, genre, price, published year, and stock.
- **Customers:** Contains customer details like name, email, city, and country.
- **Orders:** Contains order details like customer ID, book ID, order date, quantity, and total amount.

## Files Included
- `sql project.sql` – SQL queries used in the project.
- `Books.csv` – Books data.
- `Customers.csv` – Customers data.
- `Orders.csv` – Orders data.
- `questions solved.pdf` – Project questions and tasks.

## SQL Concepts Used
- CREATE DATABASE and CREATE TABLE
- SELECT, WHERE, ORDER BY, and LIMIT
- Aggregate functions like SUM, AVG, and COUNT
- GROUP BY and HAVING
- JOINs
- DISTINCT
- Subqueries and data analysis queries

## What I Practiced
- Finding books by genre and published year
- Analyzing book stock and prices
- Checking customer orders
- Calculating revenue and quantities sold
- Analyzing sales by genre and author

- MySQL Workbench
